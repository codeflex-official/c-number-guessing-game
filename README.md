# 🎮 C Number Guessing Game - Turbo C

A fun CLI game where computer thinks of a number (1-100) and you have to guess it!

### ✨ Features
- Random number generation (1-100)
- Hints: Too High / Too Low
- Attempts counter
- Turbo C compatible (uses conio.h)

### 🚀 How to Run in Turbo C
1. Open Turbo C
2. Open `game.c` file
3. Compile & Run (Ctrl + F9)
4. Start Guessing!

### 🧠 Logic Used
- `rand()` with `srand(time(0))` for random number
- `do-while` loop
- `if-else` conditions
